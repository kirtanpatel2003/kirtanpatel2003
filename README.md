## 📌 Pinned Projects

**[Red_Co-Author](https://github.com/kirtanpatel2003)** — LLM red-team + defensive monitor stack targeting the Co-Authoring Jailbreak (CoJP) vulnerability. Two-armed attack pipeline, HarDBench judge scoring, scikit-learn monitor evaluated on AdvBench and HarDBench splits. `Python` `Ollama` `Streamlit` `scikit-learn`

**[Curio](https://github.com/urban-toolkit/curio)** — Credited open source contributor. Built the real-time multi-device collaboration layer for Curio, a dataflow framework for urban visual analytics. Live presence, per-node soft locks, accept/decline proposals with first-accept-wins conflict resolution. Ships in the released codebase. `Python` `Flask` `Socket.IO` `React` `TypeScript`

**[Mini Tor Anonymity Network](https://github.com/kirtanpatel2003)** — Three-hop onion routing from scratch. Six independent processes over real TCP. Entire crypto stack in pure Python — SHA-256, HMAC, HKDF, X25519 via Montgomery ladder, AES-256-GCM — verified against NIST/IETF test vectors.

**[DiffFence](https://github.com/kirtanpatel2003)** — Diff-aware security gate that scans code changes for vulnerabilities via OSV.dev and a local LLM before push or merge. Baseline logic surfaces only new findings.
